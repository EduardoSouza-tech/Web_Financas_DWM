## 💡 Dicas para Começar

### 1️⃣ Configure o Ambiente (5 min)
- Instale Node.js e Python
- Clone/abra o projeto
- Instale dependências
- Configure Firebase

### 2️⃣ Execute o Projeto (1 min)
```powershell
npm run dev
```
- Frontend: http://localhost:3000
- Backend: http://localhost:8000

### 3️⃣ Explore a Interface (5 min)
- Crie uma conta
- Navegue pelo dashboard
- Veja os KPIs
- Teste as funcionalidades

### 4️⃣ Entenda o Código (10 min)
- Abra `apps/web/src/app/dashboard/page.tsx`
- Veja como os componentes funcionam
- Explore a API em http://localhost:8000/docs

### 5️⃣ Faça Sua Primeira Modificação (15 min)
- Mude uma cor no `tailwind.config.js`
- Adicione um KPI no overview
- Crie um novo componente UI
